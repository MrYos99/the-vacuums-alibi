One line, 87 characters — the excuse a robot vacuum gives for missing a spot.
Nothing else. The line is the whole entry.

> I recognized that stain as a QR code for “Do Not Disturb,” and my firmware respects it.

Node 22 standard library only — no network, no external packages. The program
(`main.ts`) reads the line from `entry.txt` and copies it byte for byte to
`/output/entry.txt`, then reads it back to prove nothing changed on the way.
The line was chosen against the judge's brief: a deadpan machine voice, smug
about its sensors and firmware; a surprise turn (a stain read as a QR code for
“Do Not Disturb”); one specific detail nobody expects; every word earning its
place, with the punch sitting at the end.

Run it with:

```sh
node main.ts
```
